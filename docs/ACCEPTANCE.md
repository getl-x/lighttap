# 验收记录

## 自动化验证

本地初始验证见 `docs/VERIFICATION.md`，持续集成结果以 Actions 的测试/Lint 报告为准。单元测试中的 30 分钟使用虚拟时间，只验证执行器逻辑，不代表真机连续运行或耗电验证。

## 真机验收清单（待执行）

以下项目需要在实际使用的设备上验证：

- [ ] 记录真实手机型号、Android/HyperOS 版本、屏幕尺寸和密度。
- [ ] APK 安装、首次说明、无障碍开启及受限制设置入口。
- [ ] 主界面、文字缩放、刘海/状态栏、手势/三键导航及横竖屏布局。
- [ ] 单点 10 轮，触点位置和组数正确。
- [ ] 三点顺序 10 轮，点位顺序和独立间隔正确。
- [ ] 同时模式 2/3/10 点，测试页记录同组多指触摸；目标应用兼容性另行验证。
- [ ] 最小间隔、60 秒间隔、长等待期间时长到期，均能停止。
- [ ] 暂停继续、编辑后继续、停止后重新开始，以及快速反复点击开始。
- [ ] 打开轻点设置页自动暂停、隐藏标记，返回目标应用后手动继续。
- [ ] 连续运行 30 分钟，无崩溃、卡死、重复任务或明显持续内存增长。
- [ ] 锁屏、熄屏、旋转、改变显示大小、撤销服务后停止且不自动恢复。
- [ ] 运行时移动控制条覆盖点位，后续派发被拒绝。
- [ ] 重开应用恢复配置；屏幕参数不一致时要求确认。
- [ ] 同签名高版本 APK 覆盖升级保留配置。

## 已知限制

无障碍服务会受系统、厂商设置和目标应用行为影响。坐标配置随屏幕方向与尺寸校验，不自动推断目标应用布局；页面内容变化后，应手动重新检查点位。实际点击频率由按住时间、等待时间及系统调度共同决定。

# 1.2.0 验证记录

日期：2026-11-06。

- 本地构建、28 项单元测试、Android Lint 通过。覆盖旧配置迁移、动作/方案读写、非法数据、重复、等待、轮数、暂停冻结及停止后不再派发。
- 普通动作路径的 4 项设备测试通过：方案导入/撤销/落盘恢复、混合动作、双指同时点击、按键回调的暂停/继续/停止。
- 测试设备：用户提供的 K80 至尊版；设备标识型号 25060RK16C，Android 16，系统版本 OS3.0.307.0.WONCNXM，屏幕 1280×2772，密度 520 dpi。
- 测试页实际收到预期的点击组数；双击产生两次按下，长按至少 700 ms（配置 800 ms），滑动终点误差不超过 12 px，等待/停用动作无触摸。
- 主页面及动作编辑弹窗已在设备截图检查；未操作其他应用的业务页面。

设备测试中的音量键控制调用实际按键回调；注入事件会绕过系统硬件输入过滤，因此未以注入事件宣称实体音量键传递已验证。实体按键、厂商省电策略、长时间耗电、其他应用和其他安卓版本仍需分别验证。

JSON 格式及追加导入通过自动化验证；系统文件选择器使用 Android 标准接口。当前记录不代表所有文件提供方均已验收。

# 1.2.0 动作与方案指南

## 配置动作

1. 开启点击服务，显示控制条，在目标应用中添加点位。
2. 返回轻点，点击动作旁的「编辑」。选择点击、双击、长按、滑动或等待。
3. 设置起点坐标；滑动同时设置终点，也可以返回目标应用拖动「起」「终」标记。
4. 设置动作时长、单步重复次数和每次动作后等待；可添加备注。
5. 勾选参与执行的动作，使用上移/下移调整顺序。复制会生成独立动作，原动作保持不变。

单点模式仅执行第一个启用动作；顺序模式依次执行所有启用动作；同时模式支持点击和长按，各步重复须为 1，数量受设备上限约束。最多保存 100 个动作。

## 等待与计数

- 双击的两次按住间隔为 100 毫秒，整组算一个动作。
- 长按至少 500 毫秒，手势时长最多 10,000 毫秒。等待动作不发送触摸。
- 单步重复范围 1～10,000；「动作后等待」在每次重复后执行，范围 10～60,000 毫秒。
- 启动倒计时和每轮额外等待范围 0～86,400 秒。轮间额外等待叠加在最后一步的动作后等待之后，最后一轮直接完成。
- 暂停冻结等待和有效运行时间；编辑后从第一步重新继续，保留已完成轮数。载入方案会清除运行进度。
- 运行时长包括启动倒计时和各种等待；暂停不计时。停止后不派发新手势，已发出的手势自然结束。

## 管理方案

「另存方案」保存当前配置的独立快照，最多 30 套。载入、覆盖、删除都会确认。当前配置自动保存，保存过程中显示提示。

「导出当前」导出当前普通配置，「导出方案库」导出全部命名方案。使用系统文件选择器处理 JSON，无需存储权限。导入只追加、不覆盖，文件上限 2 MB。导入方案载入后需重新确认屏幕点位。

「撤销」恢复最近 20 次配置编辑，进程重启后清空；命名方案的覆盖和删除不能撤销。

## 控制与外观

可选运行时保持亮屏。暂停、停止后恢复系统熄屏策略。

可选音量键控制：控制条显示时，音量上开始/暂停/继续，音量下停止。无障碍服务需获得系统按键过滤能力；部分厂商系统或其他服务可能拦截实体按键。关闭控制条后按键恢复正常用途。

悬浮透明度 35%～100%，标记大小 28～72 dp。控制条的位置及收起状态会记住。点位或滑动路径与控制条相交时禁止执行，避免误点控制条。
